INSTALLATION
1. Extract this ZIP.
2. Open your existing ZORVANTA website folder.
3. Keep a backup of the old folder first.
4. Replace the contents of the existing website folder with the contents of this extracted folder.
5. Deploy the complete extracted folder to your EXISTING Netlify site (not a new site).

The same navigation appears on every page, including Settings. On phones, the navigation scrolls horizontally instead of hiding the links behind a blank-looking menu.

IMPORTANT LIMITATIONS
- The AI Studio draft builder is a local example generator, not connected to a live AI model.
- Dashboard counts are sample/session values, not real analytics.
- Settings are saved only in the current browser/device.
- Contact form opens the visitor's email app and currently uses hello@zorvanta.example as a placeholder. Replace that with a real contact email before launch.
