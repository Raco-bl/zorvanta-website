DEPLOY TO NETLIFY
1. Upload the COMPLETE project contents to your GitHub repository, preserving the assets folder.
2. Netlify build settings for this plain HTML project:
   Base directory: leave blank
   Build command: leave blank
   Publish directory: .
   Functions directory: leave blank
3. Ensure the production branch is main.
4. Trigger a new deploy after all files are committed.

IMPORTANT
- This is a front-end starter, not a production SaaS backend.
- AI Studio creates a local template draft; it is not connected to a live AI model.
- Dashboard numbers are sample data.
- Contact form does not transmit/store submissions.
- Settings are browser-local only.
- No login, database, payment system, or social integrations are included.
